# 璟 · 珠宝定制工作台

门店现场定制演示工具:参数化改款式、换材质换宝石、物理渲染实时看成品,看完直接出图报价下定。

纯前端静态站,无需构建。Three.js 与 jsPDF 已本地化为 `vendor/`,离线可用。

## 启动

ES 模块需要 HTTP 环境,任选其一:

```bash
# 方式一(推荐,双击即可)
启动.bat

# 方式二
python -m http.server 8080
# 或
npx http-server -p 8080
```

然后浏览器打开 `http://localhost:8080`。

## 五个页面

| 页面 | 功能 |
|------|------|
| 款式库 | 9 个预设基础款(戒指/吊坠/耳饰),缩略图实时渲染,一键载入工作台 |
| 配置工作台 | 参数化建模 + 物理渲染视口,改参即变形;撤销/重做、收藏搭配、分屏对比、存订单 |
| 材质宝石库 | 3 种贵金属 + 7 种宝石的物理参数(密度、折射率、色散、参考价),一键套用 |
| 渲染出图 | 4 视角批量出图(1024/2048/4096),白底/场景两背景,PNG 下载,报价 PDF 导出 |
| 订单 | 存配置参数 + 客户信息,自动估金属重量/宝石克拉/报价,JSON/CSV 导出,可回载 |

## 关键技术

- **参数化几何**(`js/gems.js` `js/jewelry.js`):圆形明亮式(台面/星刻面/风筝面/上下腰面/亭部主刻面,57 面标准拓扑)、椭圆、祖母绿切(阶梯切)全部按刻面拓扑生成;戒圈按港号换算内径,戒臂宽度/金属厚度/爪数/爪粗/包镶高度/钉镶排布全参数可调,钉镶自动贴合戒臂曲面。
- **PBR 材质**(`js/materials.js`):金属度/粗糙度可调;宝石用 `transmission` 真折射 + `ior` + `dispersion` 物理色散 + Beer-Lambert 体吸收(彩色宝石的体色)。
- **焦散真算**(`js/caustics.js`):对当前宝石网格做光谱光子追迹——柯西色散折射率、斯涅尔折射、菲涅尔反射、全内反射、体吸收,光子落地面累积成图。完全由几何和物理参数计算,无任何预制贴图。
- **视口=出图**(`js/viewport.js`):交互视口与批量出图共用同一渲染管线(环境光照、PCF 软阴影、辉光、景深、轨道控制),改参数后两者必然一致。
- **报价**(`js/pricing.js`):金属体积×密度×金价 + 主石体积×比重换算克拉×克拉价 + 配石 + 工费。

## 目录结构

```
index.html          入口
css/style.css       界面样式
js/
  config.js         金属/宝石物理参数、预设款式、默认值
  gems.js           刻面宝石参数化几何
  jewelry.js        戒臂/镶口(爪·包·钉)/吊坠扣/耳钉装配
  materials.js      PBR 材质工厂
  caustics.js       光谱光子焦散烘焙器
  viewport.js       渲染视口(后处理管线、离屏出图)
  pricing.js        报价引擎
  app.js            主应用(路由/状态/历史/收藏/订单/PDF)
vendor/             three.js 0.180 + jsPDF(本地化,离线可用)
```
